One command-line tool that applies an AI model's edit to a tree of text files in any of four formats: unified diffs (even with drifted line numbers), SEARCH/REPLACE blocks, V4A patches and JSON text-editor calls. Lines are matched at three whitespace tiers, changes are all-or-nothing.

## Run it

```sh
node main.ts patch.txt
```
